# The final working Totoro Humidifier.
So the humidifier uses a sponge like material to allow water to travel to the atomizer module. 
The module requires very little water to produce mist. 
Using this and the sponges absorption capabilities, cutting but still allowing contact will let the continue to let water travel.
Since cutting the sponge doesn't affect the absorption capability, I was able to make this project reloadable when empty.
What I mean is I designed it around mason jars to hold and deliver water, and when empty, I can quickly swap to another jar to continue making mist.
